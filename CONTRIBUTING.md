# Cómo Contribuir a HELIOS

¡Gracias por tu interés en contribuir a HELIOS! Tu participación es lo que hace que este proyecto crezca y evolucione. Ya seas un desarrollador, un científico, un traductor o simplemente alguien con una idea, tu ayuda es bienvenida.

## Tipos de Contribuciones

Aceptamos muchos tipos de contribuciones:

1.  **Código:** Corrección de errores, nuevas funciones, mejoras en la interfaz.
2.  **Conocimiento:** Nuevas correlaciones, datos históricos, estudios científicos que validen la heliobiología.
3.  **Traducción:** Ayudarnos a llevar HELIOS a otros idiomas.
4.  **Documentación:** Mejorar este `README`, los comentarios en el código o crear tutoriales.
5.  **Difusión:** Compartir el proyecto y ayudar a que más gente lo descubra.

## Cómo Empezar

### 1. Reportar un Error 🐛

Si encuentras un error en la aplicación, por favor, abre un *issue* utilizando nuestra plantilla de "Bug Report". Incluye toda la información posible para que podamos reproducirlo y solucionarlo.

### 2. Sugerir una Función 💡

¿Tienes una idea para mejorar HELIOS? ¡Genial! Abre un *issue* utilizando la plantilla de "Feature Request" y descríbela con tanto detalle como puedas.

### 3. Contribuir con Conocimiento 🧠

Esta es una de las contribuciones más valiosas para HELIOS. Si tienes datos, estudios o una correlación que crees que es importante, abre un *issue* utilizando la plantilla de "Data/Knowledge Contribution".

### 4. Hacer un Pull Request con Código 💻

Si quieres modificar el código:

1.  **Haz un Fork** del repositorio.
2.  **Crea una Rama** para tu contribución (`git checkout -b feature/nueva-funcion`).
3.  **Haz tus Cambios**. Asegúrate de que el código sea limpio y siga el estilo del proyecto.
4.  **Haz Commit** de tus cambios (`git commit -m 'feat: añade nueva función de predicción'`).
5.  **Sube tu Rama** a tu fork (`git push origin feature/nueva-funcion`).
6.  **Abre un Pull Request**. Describe claramente tus cambios y por qué son útiles.

## Estilo de Código

Mantenemos el código simple y legible.
- Usa comentarios para explicar partes complejas.
- Mantén la consistencia con el estilo existente.
- Asegúrate de que la aplicación funcione correctamente antes de hacer el PR.

## Revisión

Revisaremos todas las contribuciones lo antes posible. Podemos pedirte que hagas cambios o aclaraciones. Esto es parte de un proceso colaborativo y no es una crítica personal.

Gracias de nuevo por ser parte de HELIOS. ¡Juntos, estamos iluminando el mundo!
